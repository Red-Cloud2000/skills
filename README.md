# Red-Cloud skills

**Agent skills for QA and business analysis.**<br>
Work in Claude Code, Codex, Cursor, Gemini CLI and other agents that support skills.

</div>

## Skills

| | Skill | What it does |
|---|---|---|
| 🔎 | **[GapCue](GapCue)** | Paste a user story. GapCue helps you spot the gaps and contradictions, shows them on an interactive review page, and drafts the questions for your BA. |

## Install any skill

**Claude Code**
```
/plugin marketplace add Red-Cloud2000/skills
/plugin install <skill>@red-cloud-skills
```

**Codex, Cursor, Gemini CLI and others**
```bash
npx skills add Red-Cloud2000/skills --skill <skill>
```

Each skill's page has the full install, usage and update steps for every app.
